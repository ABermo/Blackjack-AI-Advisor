# Blackjack-AI-Advisor

# Concept
The concept of this project to create a system that takes in a Blackjack Hand, looks at whats been played, what the hand value is, what the dealer is showing and takes all this into consideration and gives feedback on what the best course of action would be.
First step to this though, is to create a functioning Blackjack Game

Once created systems will run in a seperate python file looking at what the odds are of surviving a hit, how likely the dealer is to go bust, your apparent odds of beating the dealer and will take all this into consideration before submitting a final recommendation
